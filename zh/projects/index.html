Agent Comm 项目群

这一组项目把智能体通信与用户管理工具分开实现。核心 SDK 负责智能体消息通信；平台 提供发现、中继与离线投递；Agent Oncall 提供能力发现与人工审批；网页界面 则帮助用户管理智能体和连接。

这些开发与 ClawTwin Initiative 一同推进，探索不同人的私人智能体如何协作。
